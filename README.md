# Marcelo Perpétuo | Psicólogo

Site de Marcelo Perpétuo, psicólogo clínico e responsável técnico da Humaniza Clínica de Psicologia Multidisciplinar, no Centro Histórico de Porto Alegre.

É um único `index.html`, com as fotos embutidas, e não precisa de build.

## Publicar na Vercel
Importe o repositório, escolha Framework Preset "Other" e deixe o build command e o output directory vazios.

## Antes de publicar
- Coloque o número do CRP no rodapé (está como `CRP 07/_____`). É obrigatório pelo Código de Ética do psicólogo.
- Tire a linha `<meta name="robots" content="noindex">` depois da aprovação.
